# Getting Started

## New project from the template

```sh
sbt new cheleb/ThreeScalaJS --directory=threescalajs.g8
cd <name>
npm install
npm run dev
```

The generated project is a Scala.js + Vite application with a ready-to-run Three.js scene.

## Installation


```sbt
libraryDependencies += "dev.cheleb" %%% "threesjs" % "{{ projectVersion }}"
```
